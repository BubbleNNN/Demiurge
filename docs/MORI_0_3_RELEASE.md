# Mori 0.3.0 本地产品完善记录

本轮把已有陪伴、角色档案、聊天记忆和外观制作串成可直接使用的本机应用。主要交付为可执行 macOS Apple Silicon 应用包，以及可比较、可修正、可恢复的桌宠制作流程。没有上传 GitHub、发布应用商店或调用用户付费服务。

## 制作体验

- 每画风支持 1–3 张形象候选。多候选在后续动作请求前等待选择，选择持久保存；选择第二张时，动作确实使用第二张的原始图片字节。
- 单候选保留默认角色图停靠；旧任务默认单候选、四帧、自然气质，仍能恢复。
- 完成后可只修正一个动作，逐字节复用其他动作；或以选定角色图和原始参考编辑新形象，并重做该画风动作。新任务保存来源与修正说明，旧任务和成品保持可用。
- 修正阶段沿用写入请求标记、原始输出保留、显式重试和仅恢复本机保存的规则。重启、选择保存失败、参考变化、重复未完成任务均有检查。
- 新成品必须重新逐帧核对。四帧/八帧、三档气质、外观要求和动态无损图集排版沿用前一轮实现。

GitHub 方案来源为 [VPet](https://github.com/LorisYounger/VPet)、[sprite-pet-skill](https://github.com/promptwhisper/sprite-pet-skill) 和 [sprite-gen](https://github.com/aldegad/sprite-gen)；[AIRI](https://github.com/moeru-ai/airi) 仅作陪伴运行时方向参考。采用了角色基准、动作分组、持久任务和视觉核对等思路，没有复制其角色美术或运行外部生成工具。逐项阅读与授权取舍见 [上一阶段记录](PET_PRODUCTION_UPGRADE_2026_10_22.md)。

## 长期使用与数据恢复

- 取消前端对历史消息的 1,000 条静默截断；存档按每角色 100,000 条和现有总大小边界校验，超限拒绝保存并保留原盘。
- 每次正常状态更新保留上一份有效存档。启动失败提供显式恢复，原损坏文件保留；恢复作为新提交递增版本，避免已打开桌宠忽略旧版本广播。
- 密钥解密失败独立显示，允许继续本地陪伴和修改不涉及密钥的设置。重置前保留原加密文件；修复 TTS Key 状态漏报。
- 同一工作区仅一个主进程可写，重复启动聚焦现有窗口。
- 完整工作区 ZIP 保存状态、模型、2D/3D 任务与素材；不含密钥或 Chromium 缓存。导入核对路径、文件集合、CRC、SHA-256、大小、模型入口与存档结构后再落地。
- 导入保存原工作区副本和事务记录；安装中断回滚到原数据，durable commit 后退出则保留新数据并补清理。导入成功重启前继续阻止旧缓存写入。无效恢复记录停止启动。
- 主进程所有在途 IPC 都参与维护互斥，覆盖原生模型导入对话框，以及会在读取时修复检查点的任务接口。维护期间不进入新的工作区操作。

## 应用交付

`pnpm package:mac` 从当前源码重新进行 TypeScript/Vite 构建，组装独立 `Mori.app`、ZIP、SHA-256 和白名单载荷清单。运行应用不需要项目目录、Node 或 pnpm。主进程及生产依赖、前端、内置图片、字体和本机 Live2D Core 按白名单复制；不包含真实工作区、密钥、测试夹具或其他研究项目。

包内包含第三方许可和素材说明。当前是未签名、未公证的 macOS arm64 本地验收包；公开分发还需要签名公证和素材/运行时的授权确认。打包和验收方式见 [MACOS_RELEASE.md](MACOS_RELEASE.md)。

## 验证与证据

TypeScript 与生产构建通过；**258 项 Node 测试全部通过**。真实 Electron 自动制作、候选/修正、聊天与备份恢复工作流均通过。主要报告、测试日志和隔离截图位于 [artifacts/mori-0.3.0](../artifacts/mori-0.3.0/)，此版本实际应用包验收报告归档于 [packaged-release](../artifacts/mori-0.3.0/packaged-release/)。后续版本的最新包验收位于 [artifacts/macos-release-arm64](../artifacts/macos-release-arm64/)。

- Node 回归覆盖已有聊天、存储、素材导入与制作逻辑，新增候选、修正、工作区恢复、导入事务和并发边界测试。
- `scripts/test-pet-revision-desktop.cjs` 验证真实窗口候选比较、重开后选择恢复、选定基准字节、只修招手的一次新请求、其他动作复用，以及原聊天/记忆/成品保留。
- `scripts/test-workspace-recovery-desktop.cjs` 从损坏存档启动，经界面恢复、失效密钥重置、完整 ZIP 导出/导入，再由第二个真实 Electron 进程检查实际落盘状态、模型、纹理、任务及旧副本。挂起模型导入对话框时，备份/恢复被拒绝且不进入新的对话框，取消后恢复正常。
- `scripts/test-chat-desktop.cjs` 通过保存失败后的本机恢复、多窗口合并、试聊、话题边界、草稿、完整请求 URL 与 Anthropic 结构化回复回归。
- `scripts/test-packaged-desktop.cjs` 从系统临时目录启动实际包内二进制，验证生产页面、无模型的本地聊天、透明桌宠、内置逐帧素材、Live2D Core 加载与页面重载后的持久化。此脚本没有加载具体 Live2D/VRM 模型，不能代替任意模型兼容性检查。
- 工作区事务测试包含实际子进程强制退出、文件系统写入失败、恢复副本损坏、符号链接替换和提交记录 fsync 失败。没有模拟真实硬件掉电。

图像测试使用固定 PNG 响应，无真实付费图像请求。这证明输入、选择、修正、保存和播放流程正确，不能证明某个模型生成的角色更美、肢体正确或动作更自然。内置七套美术未在本轮重绘。真实画质对照仍需使用真实服务输出，并保留逐帧人工审阅。
