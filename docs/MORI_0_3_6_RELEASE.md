# Mori 0.3.6 · 读书与掌机活动

2026-11-06。延续对本机 Anime Codex 的适配，新增可制作、审核、导出和播放的两种生活活动，并用真实姿势帧完成进入/退出。

## 使用方式

在「外观工作台 → 自动制作多画风桌宠」选择「读书」或「玩掌机」。每组固定生成八帧，包含拿出道具、活动循环、收起道具，要求图像服务支持 1536×1024。每组仍是一次图像请求；其他动作沿用四帧/八帧设置，四种表情仍为四帧。增加帧数或选择不同尺寸可能影响服务费用，模型效果需实际核对。

先确认基准形象，再生成活动。成品预览新增读书和掌机按钮，逐帧审核同时覆盖进入、循环和退出。核对后启用，可在外观工作台动作区或桌宠悬浮工具栏触发。桌宠活动约持续一分钟，可随时点击停止；静态预览中的活动持续循环，方便核对。

「专心工作」本地互动在角色具备读书素材时选择读书；没有素材时仍待机。没有新增后台随机活动调度器，也不会为活动切换调用模型。旧内置角色没有新活动图，按钮不会伪装成可用。

## 生成与播放合同

- 读书：待机 → 拿书 → 打开 → 阅读 → 翻页 → 回到阅读 → 合书 → 收好。
- 掌机：待机 → 拿出 → 举起 → 游玩 → 按键 → 回到游玩 → 放下 → 收好。
- 以第一帧对齐同一基准图的身体尺度与脚底位置；角色站立活动，道具在画布内留足空间，整组保持同一本书/同一台掌机的形状、颜色与尺度。
- 八张源帧生成三个 clip：`enter_<活动>`、活动循环、`exit_<活动>`。循环只使用活动段，不反复拿出道具。进入/退出由实际生成帧组成，不以淡入淡出代替动作。
- 普通切换完成当前过渡片段后采用最新目标；多个快速点击不会积压队列。说话优先打断活动；系统减少动态效果或关闭动画时跳过过渡，显示活动静帧。
- 旧动画包没有过渡片段时使用其已有动作，不能凭空补出姿势。VRM 不会仅凭模型类型宣称支持读书或掌机。导入的 Aseprite 标签和帧序列也支持这些活动及过渡名称。
- 活动及过渡帧参与原有动画摘要、逐帧审核、角色包导出与任务恢复。重启继续制作不会重画已保存的活动。

## 来源和实现

参考本机 `$ANIME_CODEX_ROOT/shared/pet-production.cjs` 的日常活动设计和 `shared/pet-transitions.mjs` 的退出/进入组合思路。Mori 使用自己的八帧单活动请求、任务恢复、动画图集和播放器实现；没有复制源项目的角色素材或完整 112 帧合同。

主要文件：`shared/pet-motions.json`、`electron/pet-recipes.cjs`、`electron/pet-frames.cjs`、`src/animation/activities.ts`、`src/components/AnimatedIllustration.tsx`、`src/App.tsx`。
