# Mori 0.3.5 · Anime Codex 画风与制作流程适配

2026-11-06。本版参考本机 `anime-codex` 的实际源码与素材表现，接入清爽贴纸画风、保留源像素的图集整理和可见动作检查。

## 使用

打开 **外观工作台 → 自动制作多画风桌宠 → 清爽贴纸**。先提供角色原图；需要指定线条或上色时，可额外导入独立画风参考图。选好候选数量与动作后开始制作，默认先暂停核对角色形象，再继续动作。成品仍需逐帧核对并确认后启用。

清爽贴纸作为独立画风，也出现在普通形象生成、素材导入与画风工作流中。两头身、圆脸短肢、大块发束、清晰深色轮廓、平涂和单层硬阴影，与原有 2.5–3 头身软萌 Q 版分别保存。基准生成、候选修正、动作制作共用同一画风定义；角色身份仍由原图约束。新选项不会替换已有外观。

## 制作改进

- **尺寸容错**：按原有 2×2 四帧 / 4×2 八帧合同等分源图；对非整除尺寸和不超过 20% 的目标长宽比偏差，在每格横向居中、底部对齐补透明留白，不裁切、不拉伸、不重画。偏差过大仍拒绝，四帧和八帧不能互相误读。原始响应保存在任务中，成品说明记录尺寸整理。
- **保留裁切检查**：在补留白前检查原分格，不用补边掩盖被截断的手脚。算法不能识别任意拼贴布局，输入仍须遵循等分网格。
- **可见变化检查**：比较 alpha 和预乘 alpha 的可见颜色，忽略隐藏 RGB、轻微噪点和单像素差异。四帧至少两帧、八帧至少六帧存在足够可见差异。它只能排除明显无效帧，不能证明动作语义、角色身份、肢体或连续性正确。
- **贴纸透明残留**：仅对贴纸成品在图集采样前清除 alpha < 24/255 的像素。原始图片和其他画风保持不变。这个规则也会去除同等透明度的细节，适合平涂贴纸，不适合烟雾等素材；成品核对区会提示。
- **来源与恢复**：保留 Mori 的已返回图片本机恢复、明确重试、候选选择和启用前审核流程。尺寸整理与透明清理不产生额外图像请求。
