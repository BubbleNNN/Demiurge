# Demiurge 使用指南

> Demiurge 原名 Mori，0.3.26 起改名。数据目录仍是 `~/Library/Application Support/Mori`，原有角色、外观、聊天和已保存的密钥都会沿用。

Demiurge 把角色档案、对话、外观、记忆和透明桌宠放在同一个本地工作区。预制角色与本地互动无需账号或 API；自由聊天、生成新图和语音合成使用你自己配置的服务。

## 打开应用

macOS Apple Silicon 本机包位于 `release/Mori-0.3.6-macOS-arm64/Mori.app`。双击打开即可，也可以拖入「应用程序」。ZIP 位于 `release/Mori-0.3.6-macOS-arm64.zip`，适合保留构建副本。应用包自带运行环境，不需要运行终端命令。

当前包供本地使用，未签名或公证。开发与重建步骤、支持范围和包内许可见 [macOS 打包说明](MACOS_RELEASE.md)。Windows、Linux 和 Intel Mac 尚未提供经过验收的发行包。

应用包默认使用 macOS 的 `~/Library/Application Support/Mori`。开发命令 `pnpm desktop` 默认使用项目 `.local/development-v2`，两者是不同工作区。如果要把开发版里的角色和聊天带入应用包，先在开发版导出完整工作区 ZIP，再在应用包内恢复。密钥不在 ZIP 中，需要另行填写。不要直接覆盖正在运行的存档文件。

## 第一次体验

1. 打开「人物陪伴」，点击角色头部或身体，体验本地回应。
2. 在「外观工作台」预览内置七套画风，选中喜欢的角色包再启用。预览不会更换当前桌宠。
3. 对话选项选择「本地台词」，输入“你好”“给我一点鼓励”“晚安”“醒醒”。这些是明确标注的已编写回应，自由问题需要模型对话。
4. 打开「桌宠窗口」，调整大小并显示透明桌宠。支持拖动、触摸和对话，透明区域穿透由窗口设置控制。
5. 在「角色档案」修改称呼、关系、语气和相处节奏；在「相处记忆」查看、编辑、置顶或暂停使用某条记忆。

新增人物可以只填写名字建档；没有可靠证据的作品设定保持为空。已有外观可以导入；制作新外观需要核对参考原图并连接图像服务。

## 制作自己的桌宠

入口为「外观工作台 → 自动制作多画风桌宠」。先保存角色，并准备最多四张参考原图；第一张负责主要服装和轮廓。文字描述和网页链接不能代替图像输入。

在「连接与设置 → 图像」填写图像 Key、接口基础地址和模型。服务必须实际支持 `Images Edits`、原图参考和透明 PNG。聊天接口能连通，不代表它支持绘图。

制作时按以下顺序选择：

1. **画风**：只保留原作、8bit、3D、Q版四种。可同时选多种，每种独立制作。Q版会先用已配置的搜索服务查找该角色已有的 Q 版／表情包形象，下载后由模型核对同一角色且确为 Q 版，通过后参考它制作；没有通过核对的参考时，使用 Anime Codex 芙宁娜贴纸画风（只借画风，不借外形），并在候选上标注来源与原因。搜索、读取或核对失败会停下报错，不会当作没有参考。之前用旧画风做好的外观仍可查看、启用和补动作，但新任务不再提供这些画风。
2. **外观要求**：描述希望调整的比例、轮廓、材质或细节。身份与服饰仍由原始参考约束。
3. **角色候选**：每画风 1、2 或 3 张。两张或三张会全部生成后停下，供并排比较；只有选定的一张用于后续动作。
4. **帧数与气质**：默认四帧；八帧为实验选项，需要服务支持横向图像。自然、轻柔、活泼同时影响动作提示与播放时间。更多帧不保证更流畅。
5. **动作**：勾选要制作的动作组，并查看预计请求数。默认一张角色图和六组动作是七次图像请求；改为两张角色候选则为八次。

选择两张或三张候选时，可以切换「候选变化」。新建多候选任务默认「探索不同表现」：第一张均衡表现，第二张鲜明轮廓，第三张柔和神态；生成前会显示每张的说明。希望只做细微变化时选「同一方向微调」。候选数量相同，两种模式的图像请求次数相同。

这些标签记录最初的设计要求，不是对图片的自动质量评价。候选卡片和放大面板会显示已保存的方向；后续修图保留其来源，实际外观以结果和你的修改要求为准。原作画风保留原画法、比例和服装细节，只用神态与自然站姿探索变化。单候选、为已确认图补动作，以及没有方向设置的旧任务，继续采用原有流程。

还可以在「画风参考（选填）」中添加一张 PNG、JPEG 或 WebP，单张不超过 8 MiB。角色原图确定人物、服装与配色，画风图用于参考线条、上色方式、材质和细节处理。选择符合目标画风的示例，避免示例中的人物或服装影响目标角色；生成后仍要核对身份。

画风参考随本任务独立保存，重开或修正时沿用原副本。当前任务下方可以查看它；上方用于新任务的图片更换或移除，不会改变已经创建的任务。角色图生成与修图请求会附加这张图片，动作只使用选定角色图和角色原图。不会因此增加请求次数，但供应商可能按输入图片和用量计费。

「原作画风」继续以角色原图的画法为准。多画风同时选择时，独立画风参考只用于其他画风；如果只选原作画风，请移除独立画风参考。为已有确认角色图补动作时，沿用该图的外观，不接收新的画风参考。画风图和文字不能代替角色原图。

开始后，每个阶段都会保存任务与原始图片。单候选默认在角色图完成时暂停，也可关闭这个选项；多候选始终先等选择。点击「选择候选并继续」会保存选择并开始动作制作。

成品不会立即替换桌宠。对照原图试播、逐帧查看，核对肢体、身份和衔接，再确认启用。背景透明、帧数正确只能说明技术格式合格，不能代替视觉审阅。

角色候选卡片上的「放大核对细节」可以打开并排视图：左侧切换任意一张参考原图，右侧切换候选；缩放范围为适应窗口尺寸的 100%–300%，放大后可以滚动查看。透明格、浅色与深色背景用于查看白边、漏抠与半透明细节。像素候选放大保持硬边。这里的候选切换只影响查看，决定使用哪张仍需点击卡片上的「用这张继续」。

核对面板的「预览高度」还可选择 96、160 或 240 像素，按图片比例缩小显示。先看脸部与服装色块是否还清楚，再切回「适应区域」放大查细节。这个选项只改变当前查看尺寸，不修改原图、不调用服务，也不改变桌宠窗口的大小设置。

## 修正不满意的结果

修正要求不会原样交给图像模型。每次修正先由对话模型对照当前图片和角色原图理解你的要求，决定要查证的细节（例如某个发饰的形状或官方配色），再用已配置的搜索服务查找资料，最后由对话模型为图像模型写出具体的修正说明。因此修正需要同时配置对话模型和搜索服务；未配置时修正按钮不可用。搜索失败会停止并提示重试，不会跳过搜索直接修图；搜索没有找到相关资料时，对话模型只依据原图编写说明。修正记录下方会显示对话模型的理解、搜索词、与原图不一致之处和引用的资料。这一步约 2 次对话请求和 1 次搜索。

**还在选角色图时**，可以直接点击候选卡片上的「修正这张」。填写具体要求（最多 600 字），例如保留服装和发饰、调整头身比例或清理裙摆边缘，然后点击「生成修正版」。每次提交预计新增约 2 次对话请求、1 次搜索和 1 次图像编辑请求，不包含动作。

修正结果会成为新的候选，原图继续保留；完成后可与修正前候选或角色原始参考图并排放大比较。即使关闭了「先看角色图再继续」，候选修图完成后也会等待你明确选择。点击喜欢的一张的「用这张继续」，才会开始制作动作。每画风最多保留六次候选修正记录，每任务最多十二次；失败记录也占用这个上限，明确重试已有失败记录不新增记录。

修图失败或请求中断时，可以选择已有候选继续，也可以明确重试这次修正；重试会新增一次图像请求，已写好的修正说明会沿用，不再重复对话和搜索。若提示结果已经返回但尚未保存，点击「仅恢复本机保存」只保存已有图片，不需要再次调用服务。动作已经开始后，不能回头修改本任务的候选；完成后使用下面的独立修正版。

**整套动画已经完成时**，在成品下方选择「修正范围」，填写具体修正要求。

| 选择                   | 适合的问题                               | 新图像请求                      |
| ---------------------- | ---------------------------------------- | ------------------------------- |
| 只修正一个动作         | 招手多手指、小跳姿势不自然、嘴型不清楚等 | 仅该动作 1 次，其余动作原样复用 |
| 修正角色形象并重做动作 | 比例、脸、服饰或整体画法需要改变         | 角色图 1 次 + 此画风所有动作组  |

两种修正都另有约 2 次对话请求和 1 次搜索，只在开始修正时进行一次；动作分几张图绘制时共用同一份修正说明。

每份修正版都有独立记录和修正说明。原成品与原任务保留，当前桌宠继续使用原已确认外观；新版本核对通过后再启用。形象修正是参考图编辑，目前没有局部蒙版画笔，不能保证指定区域以外的每个像素不变。

修正版完成后，动作预览并排显示「修正前」和「本次修正版」。两边共用动作、表情和说话试播按钮；点击招手等有限动作会同时开始，再次点击可重播。只提供两份素材都支持的共同能力，便于直接比较。来源成品暂时无法读取时会说明原因，当前修正版仍可单独试播和逐帧核对。预览不产生新的模型请求。

参考原图或图像模型配置改变时，旧任务会停止并解释原因，避免混用不同输入。未完成的同画风任务需先继续或结束，之后再创建新的修正任务。

## 暂停与失败处理

可以在当前请求结束后暂停，关闭窗口后重新打开同一任务继续。不要为本机保存错误重新创建制作任务。

| 提示                       | 下一步                                                 |
| -------------------------- | ------------------------------------------------------ |
| 等待角色候选选择           | 对照原图选择一张，再继续动作                           |
| 素材已返回，但本机保存失败 | 点「仅恢复本机保存」，不重复请求模型；完成后再单独继续 |
| 图片未通过技术检查         | 查看原因后明确重试当前阶段，其他已完成素材保留         |
| 请求中断且没有保存输出     | 核对服务状态，再决定是否重试；供应商可能已经计费       |
| 图集超限                   | 减少动作或拆分任务，不会自动压低原始画质               |

四帧与八帧的请求数量相同，图像面积和服务收费可能不同。预览、核对、打包、导出及桌面互动不请求图像模型。

## 保存、备份与迁移

「连接与设置 → 工作区备份与恢复」提供三个入口：

- **导出工作区备份**：生成 ZIP，包含已保存的角色、聊天、记忆、外观、模型文件及制作任务。API 密钥、应用缓存和未保存的输入草稿不包含在内。
- **从备份恢复工作区**：先选择文件并校验，保留当前数据副本，再替换工作区。成功后应用重启。本机 API 密钥保持原样；跨电脑使用需要重新配置密钥。
- **打开数据文件夹**：查看实际存档、任务和恢复副本位置。

先结束当前请求和文件导入，再执行备份或恢复。备份与恢复期间暂不接受其他工作区操作。完整 ZIP 上限为 512 MiB 解压后载荷、单文件 128 MiB、10,000 个文件；模型较多时可先另存个别素材。文件集合、路径、校验摘要或存档格式不合格时会拒绝导入。

导入前副本保留在数据目录的 `recovery-*` 中；它用于恢复意外情况，不会自动删除。导入中途退出后，下次启动先完成事务恢复，再加载工作区。若恢复副本或事务记录本身损坏，应用停止加载并显示数据目录，避免继续覆盖数据。

画风参考原文件随制作任务进入完整工作区备份；单独导出角色包只携带外观及画风来源摘要。

角色包导出与完整工作区备份用途不同：角色包用于分享一名角色的档案、图片、逐帧时序和本地台词，不携带聊天、记忆或本机模型；工作区 ZIP 用于保存自己的完整使用数据。

## 存档和密钥故障

正常保存会保留上一份有效存档。启动时若当前存档无法读取，界面提供重新读取、打开数据目录，以及在存在有效副本时「恢复上一份有效存档」。恢复会保留坏文件，并使用新版本号同步桌宠窗口；它只恢复该次快照，不是所有历史版本的时间机器。

如果系统无法解密已保存密钥，本地角色、聊天记录和本地互动仍可使用。「连接与设置」会显示故障说明；点击「重新配置密钥」会保留原加密文件、清除失效凭据，然后再填写需要的密钥。模型请求在配置修复前不会偷偷改用另一个服务。

每个角色的已保存聊天允许最多 100,000 条，并受工作区文件大小上限约束；超限会明确拒绝保存，不会静默截掉旧记录。模型实际接收的近期上下文仍是单独的有界窗口，长历史不会全部发送。

## 当前能力范围

内置逐帧外观、本地互动、档案、聊天管理、记忆、桌宠、模型导入、自动制作、修正版、备份恢复与本机应用包已经接通。真实模型对话、语音和图片输出取决于所配置的服务。

八帧流程尚属实验；没有自动视觉审美评审、Live2D 自动拆层绑定、语音识别或自动更新。已有 Live2D/VRM 可以导入运行；低多边形画风的逐帧图仍是 2D，真实 3D 制作有独立服务入口。候选修图仍由图像服务按参考图编辑，不能保证只改变指定区域。实现细节与验证证据见 [0.3.0 完善记录](MORI_0_3_RELEASE.md) 和 [0.3.2 候选修图改进](MORI_0_3_2_RELEASE.md) 和 [0.3.3 画风参考与预览](MORI_0_3_3_RELEASE.md)、[0.3.4 候选设计方向](MORI_0_3_4_RELEASE.md)。

## 清爽贴纸与图集整理（0.3.5）

在「外观工作台 → 自动制作多画风桌宠」选择「清爽贴纸」，可生成两头身、深色轮廓、单层平涂的角色。先核对基准，再继续动作。等分图集的轻微尺寸偏差会本机补透明边；原图保持不变。成品说明会显示补边与低透明度清理记录。人物被裁切或帧没有足够可见变化仍需处理，不能用补边修复已经缺失的肢体。详见 [0.3.5 说明](MORI_0_3_5_RELEASE.md)。

## 读书与掌机（0.3.6）

在自动制作中勾选读书或玩掌机，每组固定八帧、一次 1536×1024 请求；先确认形象，生成后核对所有姿势。启用后，可在外观工作台的动作区或桌宠工具栏触发活动，约一分钟后收起道具，也可点击停止。已有角色必须具有对应素材才会启用这些按钮；内置七套外观没有自动增加新帧。具体流程见 [生活活动说明](MORI_0_3_6_RELEASE.md)。


## 0.3.7 工作区入口

左侧上方选择当前角色，或添加、导入一个角色。下方分为两组：

- **日常陪伴**：陪伴首页、对话与语音、相处记忆、桌面陪伴。
- **角色工作室**：角色档案、外观与动作。

陪伴首页的人物下方可以直接聊天；「设置桌面陪伴」打开大小与启动设置。页面切换保留正在输入的草稿。

在「外观与动作」中，点击「我的外观」里的卡片切换；需要新外观时使用上方「开始制作」。角色包、Live2D、VRM、逐帧动画和其他制作方式位于「已有素材，或需要其他制作方式？」中。「当前外观的表情与动作」用于展开预览与调节。自动制作仍会先等待角色图确认，再继续动作，最终核对后启用。

## 桌面生活（0.3.20 起；0.3.23 起可以待在任何地方）

她可以待在屏幕上任何地方：把她拖到哪里，她就待在哪里，头可以贴着菜单栏，脚可以踩在程序坞上。屏幕底部、每个露出的窗口上沿和桌面图标是可以站上去的地方；松手时她的脚离其中某处不到约 36 点，她会顺势站上去。站在这些地方、又没有其他事情时，她会按角色的精力、好奇心和亲近度自己决定做什么：散步、爬到窗口上沿、站到图标上、在地面上躲到窗口侧边偷看你、在你切换窗口后转过去看看、困了就地打盹。被你放到空中的位置时，她留在原处，只会就地打盹或看看你。你刚放下她后的三分钟内，她不会自己离开。活动（读书、掌机等）进行时她不会走开。

- **陪你做事（0.3.25）**：你在某个应用里打字或操作时，她会走到这个窗口旁边站着（两侧没有空位时站在它的下角），不挡住你正在看的内容。你打字时她安静地看着，时不时转头看一眼你的屏幕；如果当前外观有对应动作，她会拿出自己的东西陪你：写代码时用笔记本电脑，写文档时写日记，浏览网页或看文档时读书，听歌时戴耳机，玩游戏时玩掌机。开会时她只让开、不说话；你打字时她不会主动搭话或发出邀请。你停下五分钟以上，她回到自己的生活：散步、玩掌机、吃点心、听歌；离开二十分钟以上会打盹。窗口换了位置她会跟过去；你在工具栏里点的活动和刚摸过她时，她会先做完再过去。
- **她看得到什么**：前台应用的名称和标识、各窗口的位置大小，以及距离上次按键、上次移动鼠标过了几秒。不读取窗口标题和内容，也不记录按了哪些键；这些信息只在本机使用，不会发给对话模型。目前仅支持 macOS。
- **跑到你打字的窗口上（0.3.26）**：你在某个窗口里打字时，她会跑过去。窗口上方有空间时，她站到窗口上沿，坐下或趴着看你（需要外观有「坐下」「趴着」动作，没有时站着倾听）；有时也会在那里做自己的事，过一阵子换个姿势。窗口太高、上方没有空间时，她站在窗口旁边。
- **站在窗口上**：慢慢拖动那个窗口时，她会跟着上下移动，并小跑着保持自己在窗口上的位置；拖得太快、或窗口从她脚下滑走时，她会摔到屏幕底部。摔下来后，她可能自己跑回窗口上，也可能坐在原地生气（头上出现 💢），等你摸摸她的头哄一哄；哄好后她会回到窗口上。她生气时不会陪你玩游戏，四分钟后也会自己慢慢消气。窗口关闭或最小化时，她也会掉下去。
- **拖动**：拎起时她会随拖动方向像钟摆一样晃动；松手后她就停在那里，站上窗口或地面时有一个压扁回弹的动作。
- **工具栏**：平时隐藏。鼠标在她身上时，她脚下会出现一条小提示线；把鼠标移到那里，工具栏才会出现，移开后自动隐藏。工具栏包括对话、探索、一起玩、休息、打开 Demiurge、收起桌宠，下一行是当前外观支持的活动，最下面是大小滑块。
- **每个角色的生活方式不同（0.3.31）**：她最常做的事、空闲时的小习惯、移动方式和性格（害羞、爱捉弄人、活泼或安静）都来自角色档案里的性格、说话方式和简介。例如昔涟最爱写日记、会哼歌、轻轻捉弄你；害羞的角色被摸头会脸红（///），爱捉弄人的会回嘴，会飞的角色（档案里有翅膀、魔女、飞行等）用「飞行」动作在空中移动。
- **不再呆站着**：被召唤时她会从屏幕一侧跑进来、挥挥手，然后去做喜欢的事；空闲一会儿就会坐下、趴着、左右看看、伸个懒腰或哼歌。在你的窗口旁时，她多半在做自己的事，偶尔偷看你一眼，也会时不时主动找你玩或聊天。新制作的活动动作（读书、写日记、掌机等）里自带一格「抬头偷看你」的姿势。
- **去你的窗口**：你在某个窗口里打字时，或者很久没人理她时，她会去你正在用的窗口。没有走路动作的外观不会滑过去，而是蹦过去，或者一闪消失、再在目的地出现。
- **摸摸头**：三种方式都可以——点一下她的头；不用点击，把鼠标在她头顶左右来回蹭几下（经过发梢外面也算，你正在别的应用里工作时也有效）；或者点她脚下工具栏里的「摸摸头」按钮。她坐着或趴着时被摸头不会站起来，而是在原地回应你。
- **坐下、趴着会待一会儿**：她坐下或趴下后会待上一阵（平时约一到一分半钟，寂寞时更久），不会刚坐下就起来；这段时间里她的日常安排会等她起身后再继续。
- **工具栏位置不变**：工具栏和输入框总在她脚下展开。她最低只能站到工具栏还能完整显示的位置，所以在屏幕底部也不会跳到头顶。
- **跟着你换桌面**：切换到其他桌面或全屏应用时，她也会出现在那里，并从你切换的方向跑进来（需要 macOS；方向读取不到时从较近的一侧进来）。
- **头部大小一致**：播放时会逐帧比较头部大小，站立姿势里头部偏大或偏小的帧会以脚下为中心微调（最多 10%），坐、趴等姿势保持原样；存档和核对记录不变。
- **心情（0.3.26）**：她有开心、寂寞和生气三种心情。陪她聊天、玩游戏、摸摸头会让她开心；很久没人理她会慢慢变得寂寞（头上出现「…」，很寂寞时会露出难过的表情）；睡着时被叫醒、正在做的事被拎起打断、被从窗口上甩下来，她会生气（💢），戳她只会更生气，摸摸头最能哄好她。开心时头上会出现 ♪。心情也会改变她做的事：开心时走得更轻快，常哼歌、伸懒腰，更爱玩游戏和听音乐，陪你时也常自己找事做；寂寞时慢慢走，坐或趴在你的窗口边一直看着你，待得更久；生气时不跑不飞、跺着脚走，不来陪你的窗口，坐在一边生闷气，宁可写日记也不玩。心情会写进她的对话背景，模型回复时会照着她现在的心情说话；应用首页人物状态后面也会显示心情。
- **她会主动找你**：除了邀请你玩小游戏，寂寞时她会问你「我有点想和你说说话……」或「可以摸摸我的头吗？」。点「好呀，聊聊」会打开桌宠下方的输入框，点「摸摸头」就会摸摸她；生气时她只会请你哄哄她。这些邀请同样遵守「不打扰」的频率限制，你打字或开会时不会出现。
- **一起玩**：工具栏的爱心打开小游戏。游戏显示在她头顶的小气泡里，由她用动作表演：猜猜藏哪只手时她双手合起来藏好星星，猜对会跳一下、猜错会摇头；一起读时她捧着书；接星星时星星落在她身边，点住星星即可，每接到五颗她会跳一下。没有对应动作的外观会保持待机。
- **直接对话**：点工具栏的对话按钮，她脚下会出现输入框；输入后按 Enter 发送（Shift+Enter 换行，Esc 收起），回复显示在她头顶的气泡里，不需要打开 Demiurge 主窗口。输入框左侧的时钟按钮打开完整对话记录。点她头顶的气泡也可以直接回复。
- **气泡位置**：说的话在她头顶，工具栏和输入框在她脚下。她靠近屏幕上边时，说的话移到脚下；靠近屏幕下边时，工具栏移到头顶，两者不会重叠。
- **大小**：拖动工具栏里的大小滑块（45%–260%），或在桌宠身上滚动滚轮、在触控板上捏合；「设置 → 桌面陪伴」也有同样的滑块，选择预设大小会取代自由大小。应用首页的人物同样可以滚动、捏合，或在人物设置菜单中放大缩小。
- **位置记忆**：收起桌宠再打开，她会回到上次所在的位置。
- **不打扰**：需要回应的邀请只会在你停下键盘鼠标 20 秒到 10 分钟之间出现，间隔约 18–40 分钟（越亲近越短），每小时最多两次；拒绝或忽略后间隔会再拉长。头顶的闲聊每 6 分钟以上一句、每小时最多五句，你离开时不说。你离开 5 分钟以上再回来时，她会打招呼。
- **窗口和图标位置**只读取几何信息，不读取窗口内容或文件名；图标需要允许 Demiurge 访问 Finder。可在「设置 → 桌面陪伴」关闭自主探索。

在「外观与动作 → 我的外观」中，把鼠标移到卡片上会出现删除按钮。删除内置外观后不会在下次启动时恢复；由制作任务生成的外观删除后，原始素材仍在任务中，可重新整理。

## 清晰优先的动作（0.3.21）

「自动制作多画风桌宠」的「动作清晰度」默认是「清晰优先」。图像服务每次输出约 157 万像素，一张图里画的姿势越少，每个姿势分到的像素越多：

| 动作类型 | 清晰优先 | 节省请求 |
| --- | --- | --- |
| 生活、睡觉、跑步、聆听、办公（十二帧） | 3 张图，每张 4 个姿势 | 1 张图 |
| 眨眼、说话、招手、点头、摇头、小跳、表情、拖动（四帧） | 2 张图，每张 2 个姿势 | 1 张图 |
| 全选二十组动作加一张角色图 | 约 53 次请求 | 21 次请求 |

同一动作的几张图会互相参考，生成后按共享的中心线和脚底线拼合，并用相邻帧的身高校正各张之间的比例差。眨眼、说话、点头和表情帧直接对齐待机帧。

成品图集较大时分页保存：待机和常用短动作在第一页，其他动作各占后面的页。图集存放在数据目录的 `skin-assets` 文件夹，以内容摘要命名，工作区备份和角色包导出会一起带上；已确认的审核记录不受影响。桌宠只加载正在播放的动作所在页，最近用过的页保留在内存里。

已完成的旧任务按原来的布局保存，「重新整理动画」不能增加像素。想要更清晰的动作，请新建制作任务。

## 社区：下载与分享（0.3.32）

侧栏的商店图标打开「社区」。目录放在项目的 GitHub 仓库 `community/` 里，应用只读取它：

- **桌宠**：别人分享的角色包，点「添加」后成为一个新角色，档案、外观和动作都随包带来，不用重新制作，也不会改动你已有的角色。
- **插件**：只包含数据（爱好、小习惯、移动方式、性格表现和台词），不运行代码。可以作用于所有角色或某一个角色，安装后立即生效，随时可以移除，记录保存在数据目录的 `plugins.json`。
- **分享我的桌宠**：先导出当前角色的角色包，再在打开的 GitHub 页面里附上文件提交。角色包不包含密钥、聊天记录或本机模型路径。请只分享原创角色，或你有权分享的角色与素材。

下载的每个文件都会按目录里记录的大小和 SHA-256 核对，不一致就停止使用；通过核对后再按本地导入的同样规则检查。投稿方式见 [community/README.md](../community/README.md)，桌宠模块的组成见 [PET_MODULE.md](PET_MODULE.md)。
