# Mori 0.3.9

新建桌宠任务默认清爽贴纸和完整二十动作包，包括四向跑步。
生活、睡眠、倾听和跑步采用十二格原画：进入、循环、退出各四帧。
移除新版生活动作的强制站立限制；新增坐下、接书、桌椅、蜷缩、醒来起身的具体姿势要求。
同一角色动作共享基准与已完成动作参考，固定配准避免按脚步反复居中；
插画帧按原始像素保存，不在图集超限时自动降采样。

修复日常调度提前覆盖手动活动的问题；手动选中生活动作会获得完整一分钟，并优先于自动调度。

旧任务与角色保留；需要新建任务才能使用新的制作流程。
本版没有自动为用户发起图像生成，也没有替换当前角色素材。

流程比较与复现方法见 [迁移记录](ANIME_CODEX_MIGRATION.md)。
