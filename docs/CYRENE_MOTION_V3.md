# 昔涟四画风动画 v3

2026-10-05。本轮按用户确认的范围，只重新制作原版、8-bit、低多边形和飞天小女警。精绘、Q 版、复古像素继续使用 v2 图集，注册表仍保留七套外观。原有静态图、源图、旧版图集和开发工作区数据保留。

## 动作与制作方式

每种更新画风包含 16 张完整人物姿势：中性、半闭眼、闭眼、轻微呼吸、小口型、大口型、开心、思考、抬臂、举手、两张挥手、两级点头、闭眼休息和休息呼吸。姿势直接依据已确认的对应画风立绘重新绘制，没有用整张图片旋转、网格变形或叠加旧手臂模拟动作。

每种画风拆成四张 2×2 姿势源图：`face`、`speech`、`wave`、`rest`。与原来的密集拼图相比，同一次输出用于更少的完整人物，保留更多实际源细节。每张源图均为 1024×1536；这里不把整张源图的分辨率当成单个人物分辨率。

| ---------- | ------------- | ------------- | --------- | --------------------------------------- |

| 8-bit      | 315–316 px    | 598–656 px    | 2136×2706 | 96×128 网格、最多 16 色、最近邻整数放大 |

人物源高度由透明轮廓的 alpha 边界测得；图集包含周围留白。8-bit 源 PNG 是绘图素材，播放器才将其落实为明确的 96×128、16 色网格。复古像素保持原有 64×96、32 色规格。

招呼使用抬臂、举手、挥手、回落的关键姿势，完整时长约 1.79 秒；点头约 0.94 秒，结束后恢复待机。休息单个关键姿势保留 2.2 秒，避免频繁来回切换。

## 通用口型与质量验收

动画格式新增可选 `mouthFrames`：闭嘴、小口型、大口型的帧索引。实际朗读时根据已有音量信号选择对应帧，静音或无效音量闭嘴；无音频预览继续按时序播放。手势、休息和暂停保留优先级。新自动桌宠制作也输出该映射，无需新增图像请求。旧动画没有该字段时继续使用既有口型时序。

这是音量驱动的开合，不是音素级口型同步。当前姿势仍是 16 张关键帧，没有连续手绘补间；动作之间的脸部、服装和比例一致性仍有继续改善的空间。

发布前使用通用完整人物切帧、图集预算和逐帧视觉验收。记录绑定源像素及动画结构摘要；换图、换裁切或换时序必须重新核对。代码没有按昔涟的名字、飞天小女警画风或某个坏帧编号绕过质量门槛。相关机制见 [动画质量约定](ANIMATION_QUALITY.md)。

共使用 22 次内置 `image_gen` 调用，最终保留 16 张源图。六张失败候选因人物相连、边界裁切、排版或表情错误被退回，失败源图和提示词保留。没有调用用户配置的图像 API。视觉验收来自 Codex 对全部新姿势及透明合成结果的检查，不是自动解剖检测，也不是用户对新增动画的最终美术认可。

透明 PNG 曾在原始图集预览中呈现彩色杂点。比较 Electron 原始解码、裁切像素及 Chromium 的浅色/深色背景合成后，没有发现裁切新增的损坏；低 alpha 像素的 RGB 在不同预览背景上容易产生误判。保留原始 alpha，没有为了这一预览现象修改通用透明通道逻辑。

本轮 175 项单元测试全部通过，TypeScript 与 Vite 构建成功。新增的口型自动打包、任务重启及角色包导出断言也通过。四种画风的原生播放回归全部通过，模型请求数为零；没有在本轮调用真实图像或 TTS 服务做 API 联测。

实际开发窗口已打开原有 `.local/development-v2` 工作区，继续使用用户当前选择的飞天小女警外观。核对了既有角色、外观图片、消息、记忆与设置，密钥文件字节保持不变；两条旧的待核对素材仅补充动画结构摘要。实际开发版截图及报告为 `.local/cyrene-motion-v3-development.png` 和 `.local/cyrene-motion-v3-development-verification.json`。
