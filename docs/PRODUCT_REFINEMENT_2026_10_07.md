# Mori 产品完善记录 · 2026-10-07

本轮覆盖新增角色、动画播放、角色对话、桌宠尺寸、互动和界面。沿用已确认的美术素材；没有重新生成图片、改写角色设定，或增加播放时的模型请求。

## 改动前与改动后

| 范围 | 原有问题 | 本轮实现 |
| --- | --- | --- |
| 新角色 | 关闭或刷新建档窗口会丢掉输入；相同人物可重复建档；第一套外观未必可用 | 仅在本机保留建档草稿；同步提交锁；按名字与作品续接已保存档案；按归属、验收状态和当前参考图筛选外观；每个角色分别记住外观选择 |
| 准备流程 | 档案、原图、动画、语气和台词是否齐备不直观 | 首页提供五项准备状态及继续完善入口；无素材状态压缩留白；静态 GLB 不冒充互动动画 |
| 动画 | 不同透明边距影响展示大小；显式闭眼表情可能被待机眨眼覆盖 | 一套动画共用所有姿势的透明轮廓并集和固定比例；不逐帧重缩放；显式表情优先于中性眨眼；日常表情停留后回到中性待机 |
| 对话 | 已有资料约束，但欠缺近期表达连续性和动作语义约束 | 按问题选择台词例句，提供角色编写的场景台词和最近回复开头；普通聊天优先一到三句；强调身份、作品、关系和未知设定；模型输出再检查可用表情、动作语境和重复动作 |
| 桌宠 | 固定窗口尺寸，无法适应长身与大头画风 | 轻巧／适中／醒目三档，可预览并同步到已打开窗口；按素材比例计算窗口；缩放以脚底位置为锚点，边缘位置受当前显示器工作区限制 |
| 互动 | 透明矩形也能触发点击；主界面和本地聊天使用两套事件配置 | 共用场景规则数据；逐帧角色按实际像素透明度命中；头部与身体分别回应；安静、克制的角色使用更收敛的姿势和表情；每类场景独立轮换台词 |
| UI | 设置缺少可视反馈；未完成角色不易接续 | 增加桌宠预览和尺寸选择卡片、建档草稿状态、角色准备进度；保持角色配色、折叠设置和人物下方输入；回复气泡自动收起 |

## 工程边界

- 新增 `Settings.petSize` 与 `AppState.preferredSkins`，均为可选字段。旧存档不要求迁移，也不会因读取就新增偏好。删除角色或外观后，失效偏好会在校验时移除。
- 草稿只包含姓名、作品、补充设定、资料链接和建档方式，不包含服务配置或密钥。清空草稿不会删除角色。
- 名字与作品共同限定续接对象；相同名字、不同作品保持独立。已保存的档案与聊天不会被新表单覆盖。图片收集失败时档案仍然保留，可以继续补图。
- 原生聊天与桌宠打开前，检查角色归属、生成图审核及参考图摘要；生成动画还需完整帧审核。未核对或失效素材不会作为原生动作能力来源。打开不合法桌宠的错误通过 IPC 返回界面；切换到无可用外观的角色时收起旧桌宠。
- 新增 `src/animation/framing.ts`。共同边界在帧准备阶段测量一次，保留所有姿势的空间；完整原始帧继续绘制，不拼接肢体，不生成新姿势。像素画仍按整数倍放大，非像素画保留原纹理与 HiDPI 绘制。
- 逐帧像素点击从 CSS 坐标换算到画布像素，再按整套角色边界判定头部／身体。头部比例按画风设置，属于几何启发式，不是人体关键点识别。静态图和导入模型仍使用近似中央区域；本轮精确透明命中适用于逐帧画布。
- `shared/companion-events.json` 是前端触摸与原生本地聊天共同的场景规则。安静角色倾向点头，低亲近倾向的角色表情更克制；已有作者台词不被改写。此处的性格倾向不是关系进度。
- 模型对话仍是一轮一次请求，无额外评审模型。规则能限制显示的动作和上下文，不能保证任意模型输出绝不 OOC。实际供应商对话质量未在本轮做在线测评。
- 内置素材仍为关键姿势逐帧动画。低多边形外观仍是 PNG；语音口型仍按音量切换，未变成真实 3D 骨骼、Live2D 或音素口型。人体结构与角色相似度仍需素材审核。

- `scripts/test-chat-desktop.cjs`：本机 HTTP 固定响应验证取消、保存失败恢复、窗口合并、角色试聊、新话题、草稿、精确 URL 和 Anthropic 结构化输出。取消、写盘失败和合并冲突日志是有意注入的验收情景。
