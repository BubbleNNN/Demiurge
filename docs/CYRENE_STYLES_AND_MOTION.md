# 昔涟外观与动画制作记录

## 2026-10-05：四画风较大动作源图与音量口型

按用户确认范围更新原版、8-bit、低多边形和飞天小女警为 v3。每种画风以对应已确认立绘为参考，拆成四张 2×2 姿势图，共 64 张新姿势；精绘、Q 版和复古像素的 v2 图集及元数据保持不变。原版人物源高度由 370–376 提升到 733–744 像素，其他非像素新图同样保留更多实际源细节。8-bit 播放网格提升为 96×128，仍限制 16 色。

招手加入抬臂与回落时序，点头完成后回到待机，休息降低切换频率。通用动画格式新增可选闭嘴、小口型和大口型映射，使用现有语音音量信号选择帧，新自动制作结果也输出该映射。全部新姿势完成源图及透明合成视觉检查，再通过绑定像素与动画摘要的通用发布门槛。详见 [四画风动画 v3](CYRENE_MOTION_V3.md)；下面保留 v2 及更早的轮次记录。

## 2026-10-04：七种保留画风加入动画

原作画风、精绘、Q 版、飞天小女警、复古像素、8-bit 和低多边形 3D 各新增 16 张姿势帧，使用内置 image_gen 以各自已接受的立绘为直接参考。写实、水彩、毛绒和手办没有生成新动画。当前播放文件为 `public/art/cyrene-{style}-motion-v1.png`，时序、逻辑分辨率与像素调色板共用 `shared/cyrene-motion-pack.json`；旧静态文件保留。

这些动画覆盖待机呼吸、半闭眼/闭眼眨眼、小/大口型、招呼、两级低头、闭眼休息，以及开心、思考、困倦姿势。招呼/点头为有限动作，结束恢复待机；聊天、头部点击和透明桌宠读取同一套实际能力。当前没有摇头、跳跃、难过和惊讶帧。16 张关键姿势的过渡仍需视觉审阅，低多边形 3D 仍是 PNG 序列，不是绑定模型。

原始输出、参考解包、固定比例与脚底注册仅用于图集打包，人物姿势来自绘图输出，没有回到整图摇晃或面部贴片方案。复古像素使用 64×96 / 32 色，8-bit 使用 48×64 / 16 色。详见 [当前动画与验证](CYRENE_MOTION_V1.md) 和 `CYRENE_MOTION_V1_MANIFEST.json`。下方记录为静态素材及旧八格动画的历史状态。
