# Mori 0.3.1 · 视觉核对改进

0.3.0 已提供多候选和独立修正版，但角色候选只有缩略图，修正前后需要切换任务才能比较。0.3.1 增加两种直接对照方式，让制作结果是否更好更容易判断。

## 放大候选

候选卡片新增「放大核对细节」。内联核对面板支持：

- 参考原图与当前候选并排显示；可切换已保存的任意一张参考图与任意候选。
- 相对适应窗口尺寸的 100%–300% 缩放；超出窗口的图像区域可滚动，也可通过键盘聚焦图框滚动。
- 透明格、浅色与深色背景，便于发现漏抠、白边和细小半透明饰物。
- 像素与 8-bit 候选保持最近邻显示，不用平滑插值改变像素边缘。

切换这里的候选只改变查看对象。任务仍处于等待选择状态，必须点击候选卡片上的「用这张继续」才会保存基准选择并开始动作制作。

## 修正前后同时试播

有来源成品的修正版并排显示「修正前」与「本次修正版」。两边共用动作、表情和说话试播控件；有限动作可以反复点击重播。按钮仅启用两份素材都支持的能力。

来源成品从原任务读取，异步结果绑定当前任务；切换任务或关闭工作台后不再应用旧回复。读取失败显示说明，并保留当前修正版的独立试播与逐帧核对。视觉核对、选用与发布审核仍绑定当前成品，不从原版本继承。

## 验证

TypeScript 与生产构建通过，**258 项 Node 回归全部通过**。原有自动制作原生回归及独立 macOS 应用包验收通过。`scripts/test-pet-revision-desktop.cjs` 在隔离数据目录中的真实 Electron 窗口验证：

1. 打开第二张候选的放大视图，实际图片字节与第二张候选、原始参考一致。
2. 放大至 200% 后图框可双向滚动，深色背景切换生效；切换查看第一张候选后任务仍等待选择。
3. 上述查看操作没有增加图像请求；随后选择第二张，动作继续使用第二张原始字节。
4. 单动作修正版仅新增一次图像请求，其他动作和原成品保持原样。
5. 修正前后两块实际画布分别显示来源成品与修正版；共用招手按钮令两块画布均进入招手片段，结束后均回待机，再点可重播。
6. 比较与重播不调用模型；900 像素窗口保持无水平溢出。
