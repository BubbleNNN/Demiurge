# 角色包与本地互动

Mori 的主要使用路径是预制素材、角色设定和本地行为。AI 绘图与建模是可选制作工具；程序像素绘图标为实验，不在缺少图像配置时自动选中。

## 新增任意角色

「添加角色」默认直接建立档案，不调用模型。名字必填，作品、补充设定和参考来源可选；设定只保存为用户填写的摘要，未填写的外貌、语气和原作台词保留为空。参考来源是尚未整理的网页链接，不被当成已验证的原作事实。最多六个公开 HTTPS 链接，每行一个；图片收集遵循现有网页身份匹配与网络读取限制。

名称和作品同时用于匹配已保存在本机的人物素材。昔涟支持已知中英文名称与作品别名；缺少作品时列出同名结果供用户核对。待审核或被拒绝的生成候选不作为可用角色包。选择已有素材复用已有角色 ID、编辑后的设定、聊天与服务配置，不重复建档。未知人物或相同名字但不同作品不会套用昔涟素材。

新档案保存后进入外观与动作设置。社区索引和用户提供的资料页可匿名收集原图；网页图片先保留为候选，经用户选择保存后，主参考可直接启用为静态桌宠。也可导入 PNG 动作文件夹、Aseprite/Mori 图集、Live2D 或 VRM，并试播后显式保存。界面只列出实际素材能力；图片并不自动包含肢体动作。

新增「自动制作多画风桌宠」可用图像编辑 API 将参考原图转成独立画风基准、动作姿势帧和透明图集。成品先保留为待核对候选，试播并确认后才能启用或导出。任务支持暂停续做及只恢复本机保存；真实模型的还原度和动作自然程度仍须审阅。[制作与验证说明](AUTOMATIC_PET_PRODUCTION.md)。

当前精选包只有昔涟。任意新名字并不能在无素材、无图像服务时自动得到多种画风的精美原画或完整绑定动画；每种画风需已有原画、作者制作的素材或可选的图像服务。部件拼装编辑器和自动匹配第三方桌宠市场尚未实现。未提供角色专属本地台词时使用明确标记的通用场景回应，不编造角色语气。

当前人物的角色包页面默认显示自己的素材；「精选角色包」作为独立页签，需要明确点击使用才切换人物。首页「准备外观与动作」可以再次打开当前角色的设置流程。

## 首个精选角色包

「昔涟 · 此刻的陪伴」现在包含七种保留画风，每套使用 16 张新制作的姿势帧，来自各自已接受的静态参考。原作画风、精绘、Q 版、飞天小女警、复古像素、8-bit 和低多边形 3D 都能试播待机、招呼、点头、闭眼休息、眨眼与口型；同时提供开心、思考和困倦。安装和播放无需绘图调用，不宣称素材为手绘或原作。

播放、聊天能力选择与导出共享 `shared/cyrene-motion-pack.json`，导出内嵌动画 PNG 字节、时序与调色板。低多边形 3D 是 PNG 姿势序列。没有对应素材的走路、摇头、跳跃、跳舞、投喂等不在能力列表中。历史八格动画的时序仍保留在 `shared/cyrene-sprite.json`。

安装角色包不覆盖已有角色的档案、设定、台词或聊天。相同包不会重复添加；已有昔涟缺少本地互动配置时，仅补上 `companion`。选择外观后显式切换角色，服务配置和其他角色不改变。

## 本地台词

新工作区默认 `settings.chatMode = "local"`；旧工作区缺少该字段时保持模型路径。可以在聊天栏或服务设置中切换。模型失败不会自动改成本地台词。

角色可携带可选配置：

```json
{
  "companion": {
    "version": 1,
    "replies": {
      "greet": ["你好，今天想做些什么？"],
      "touch": ["我在。"],
      "headpat": ["谢谢你的关心。"],
      "poke": ["嗯？我在听。"],
      "rest": ["先休息一会儿吧。"],
      "wake": ["休息好了，我们继续。"],
      "unknown": ["这句还没有对应的本地台词。"]
    }
  }
}
```

事件包括 greet、touch、headpat、poke、drag、rest、wake、comfort、thanks、focus、farewell、unknown。headpat 和 poke 分别用于首页摸头与戳一戳。每场景最多 12 句、每句最多 1000 字；编辑器每行一句。空场景使用简短通用回应，未知场景不伪造自由答案。关键词规则定义于 `electron/companion.cjs`；模型、搜索与 TTS 都不参与本地回复。聊天中以 `origin: "script"` 标记，保存 `interaction` 用于休息/唤醒；这些台词不进入原作来源事实，也不自动形成长期记忆。本地文字目前不提供本地语音，朗读按钮禁用。

本地聊天循环使用已保存的本地回复数选择变体。点击/拖动回应临时显示，不写入对话或记忆。缺少自定义台词时可以直接使用通用互动，并在编辑器补充。首页默认只显示最新回复气泡，完整对话记录按需展开，已有记录仍保存在本机。

## 动作调度

- 动作仅从实际图集/模型能力中选择，表情也有能力回退。
- 招呼播放完整的已制作时序后恢复；较低优先级的主动招呼不能抢占正在播放的互动或回复。
- 桌宠普通点击有四秒冷却，首页摸头/戳一戳共享 1.8 秒触摸冷却，招呼有八秒冷却；休息持续到显式唤醒或本地“醒醒”意图，主动动作不会唤醒角色。摸头与戳一戳的 UI 粒子反馈不代表素材具备新肢体动作。
- 活跃程度、亲近程度决定主动招呼间隔；低活跃角色点击不强制招手。聊天忙碌、说话、窗口不可见、暂停动态效果时不主动招呼。
- sleep 动作若提供多帧，按作者时长循环；暂停时保持首帧。七种精选昔涟都有两张闭眼休息关键姿势。

## 可携带导出

沿用 `version: 1` 角色 JSON 包，包含 `character` 与 `skins`。2D 图片内嵌 data URL，sprite 为动作图集与时序。内置素材在导出时转成内嵌图片，去掉对本机 builtin 文件的依赖。旧版 2×2 图集只导出原来显示的左上姿势，作为单帧，不补造动作。

Live2D、VRM、GLB 文件仍需单独导入。包不携带聊天历史、个人记忆、API Key 或设置；导入分配新的角色及外观 ID。格式按现有存储限制验证，拒绝跨角色素材、未知事件、路径逃逸与超限文本。

## 验证

`tests/companion.test.cjs` 覆盖安装与数据保留、台词匹配和变体、未知消息、能力过滤、动作优先级/冷却/休息、性格间隔、自包含 PNG 与时序导出、旧图集及非法输入。

`scripts/test-companion-desktop.cjs` 使用独立目录、原始随项目图片及真实 Electron 界面和 IPC，任何 API 调用直接失败。覆盖预览不修改状态、启用角色包、本地聊天、编辑并连续保存台词、休息唤醒、导出导入、重载与透明桌宠。它验证播放与数据流程，不证明任意角色包的美术质量。

`scripts/test-character-creation-desktop.cjs` 使用独立工作区和公开网页图片测试资源，验证零 Key 名字建档、不同作品匹配、复用素材不重复建档、候选核对、静态原图启用、动作文件夹导入、本地台词、原有档案与配置保留和重载。测试图片仅验证数据流程，不代表为新角色制作了原画。
