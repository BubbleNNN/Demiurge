# 昔涟立绘重制 · 2026-09-30

本轮交付是一张可玩角色形态的全身透明 PNG，名称为「与你再会 · 原图重制」。它通过内置 image_gen 工具直接输入四张参考图生成，作为开发版中可查看的候选立绘；没有记录用户身份审核通过，也没有把它升级为可以派生表情的已确认基准。

## 图像来源与输入

来源页面：[HoYoWiki 昔涟条目](https://wiki.hoyolab.com/pc/hsr/entry/4003?lang=zh-cn)。条目由 HoYoWiki 收录，图片来自其 HoYoverse CDN。来源并不意味着本项目生成结果是官方素材。

实际输入按顺序为：

1. 游戏待机动作 1 的首帧：锁定站姿、服装轮廓、前后裙长和鞋饰。下载原 GIF，仅用 sips 将首帧转为 PNG，没有重画参考图。
2. 条目角色立绘：核对服装纹样、蓝紫渐变与配件细节。
3. 角色头像：核对面部、刘海、眼睛和侧边发饰。
4. 星魂碎片 1：核对背部编发与晶体发饰。

输入图片本身通过 `referenced_image_paths` 发送；文字仅说明各图用途和桌宠站姿要求。没有输入以前的错误立绘，也没有用文字摘要替代原图。

[精确生成提示词](./CYRENE_REDESIGN_PROMPT.txt)及[来源 URL、输入输出 SHA-256](./CYRENE_REDESIGN_SOURCES.json)随代码保存。原始参考图保存在 Git 忽略的 `.local/cyrene-reference/`，并已导入本机开发档案的四个参考图槽位；不随公开代码捆绑分发。

## 交付与核对

- 输出：`public/art/cyrene-reference-v3.png`，1024 × 1536，RGBA。通过原始 alpha 数据检查确认透明背景，保持生成器输出不作脚本抠图或重新压缩。
- 可见变化：恢复蓝紫色渐变长后摆、短前裙、胸前紫色纹样、晶体与花形发饰，以及原作的粉色长发造型。采用正面欢迎姿态，便于桌宠展示。
