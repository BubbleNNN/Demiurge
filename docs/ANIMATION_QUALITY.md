# 动画质量与分辨率约定

2026-10-05。本规则适用于任何角色、任何画风；角色名、手臂数量或某张错误帧的索引不应出现在播放或验收逻辑里。

## 先分清三类检查

1. **文件和边界**：真实 PNG alpha、内容面积、留白、切帧边界、动作索引、时长和资源预算。这些检查可以自动执行。
2. **角色与肢体**：脸、服装和饰物是否一致；肢体数量是否符合该角色；手是否与对应的手臂相连；移动后是否还残留原位置的手。这需要视觉核对。透明背景、像素差异或轮廓连通性不能证明解剖正确。
3. **动作衔接与清晰度**：试播起手、主姿势与恢复，观察脚底和人物尺度；按实际窗口尺寸与屏幕像素密度检查是否需要放大源纹理。

自动制作和程序动画都先保存为候选。核对页显示全部帧，可以放大查看；逐帧确认以及肢体、身份、衔接三个项目完成后才允许启用。`review-skin` IPC 再检查完整且无重复的帧列表、PNG 摘要和动画结构摘要；绕过界面按钮也不能跳过。核对记录随角色包保存。已绑定的图像或时序变化会要求重新验收。

历史审核记录保留兼容，不能解释成已通过本轮新增的逐帧核对。导入的手绘或外部角色包不会被自动宣称“解剖正确”。当前没有一个可靠的自动数手模型，也没有自动付费重试。

## 网格只是排版建议

生成模型不保证人物严格落在等分格子内部。一只脚或头饰可能跨过数学网格边界，直接等分裁切会丢失它，并把它带进相邻帧。

通用发布工具支持 `crop: "alpha"`：依据完整透明轮廓识别人物，按中心映射到预期行列，再保留一像素抗锯齿边距。数量不符、人物相连、较大分离部件造成歧义、触及整图外边缘或间距不足时停止发布。它只确定裁切区域，不修补肢体，不用轮廓代替视觉审核。带较多悬浮部件、非透明背景或复杂遮挡的素材应提供独立姿势 PNG/明确帧坐标，不能强行套用此方法。

普通 API 制作流程仍要求四格图片在每格中留白；一旦发现格边裁切就停止该阶段并保留原始结果，供用户选择重做。不能自动把被裁断的手当成正常素材。

## 逻辑尺寸与真实像素分开

`SpriteAnimation.width/height` 表示统一构图的逻辑画布。`frames[i].rect` 表示源图集中的真实纹理坐标，二者不必相等。例如逻辑画布可以是 128×192，真实单帧可以是 1024×1536。

- 非像素画风保留原始采样密度；不同分辨率的动作帧可以放在同一图集中。改变纹理尺寸不应改变人物的屏幕大小。比例不同的素材保留留白，不拉伸人物。
- 像素画风有意按声明的逻辑像素网格与调色板绘制，保持最近邻、硬透明边缘和整数放大规则。
- 不能把 4×4 拼图的整图分辨率当成单帧分辨率。1024×1536 的整图等分后，一格只有 256×384；插值到 384×512 并不会增加细节。
- 工作台会显示明显放大时的单帧像素与倍率。Retina 显示需要计算 CSS 尺寸乘以设备像素比例。若原始帧不足，需要重新制作更高分辨率的动作源图，而不是添加一个“高清”标签。
- 单图集仍限制为 8 MiB、8192 边长与明确内存预算。超限停止并提示减少动作或拆分包，不再静默降到轻量尺寸；原始文件和任务保留，不重复请求模型。

`prepareSpriteFrame` 只为静态缩略图准备一帧，避免每张缩略图同时解码全部高清帧。播放侧另有纹理内存预算，超限明确失败。

## 口型与动作时序

动画可以声明 `mouthFrames: { closed, small, wide }`，三个值是实际绘制的闭嘴、小开口、大开口帧索引。存在语音音量输入时，播放器根据音量选择对应姿势，静音或无效音量回到闭嘴帧；有明确动作时仍优先播放动作。没有语音输入时使用既有 talk 时序预览。旧动画没有该字段时保持原有行为。它是音量驱动的开合，不是音素级唇形同步。

这份映射随 JSON 导入、角色包导出和审核摘要保存；改变它会使旧的动画结构审核失效。制作新说话帧时必须明确“小开口”和“更大开口”的区别，不能仅凭任意两个表情自动推断。

## 内置素材发布

`scripts/compile-motion-pack.cjs` 读取源清单与逐帧视觉验收记录。清单可以为任意角色指定 PNG、网格/独立帧、裁切策略、逻辑画布、调色板和时序。发布前验证每帧像素摘要与验收记录，再验证最终动画结构摘要；源像素、裁切或时序变化都会使旧记录失效。所有输入检查完成后才写出新图集。

```sh
node node_modules/electron/cli.js scripts/compile-motion-pack.cjs shared/cyrene-motion-source.json --inspect
# 查看源图、检查每帧并更新对应 reviewFile；inspect 本身不会批准素材。
node node_modules/electron/cli.js scripts/compile-motion-pack.cjs shared/cyrene-motion-source.json
```

昔涟构建脚本只指定这个清单，然后调用通用工具。它不包含“这个人物删除某只手”或“某帧替换成静态图”的播放特例。

## 回归证据

`tests/animation-quality.test.cjs` 覆盖漏检帧、重复索引、旧图片/时序摘要、发布审核、高清纹理、比例与内存预算，以及跨格人物与相连人物的裁切检查。

`scripts/test-animation-quality-desktop.cjs` 在隔离 Electron 状态中使用真实 1024×1536 素材配合 128×192 逻辑尺寸，验证原生像素保留、低分辨率提示、像素网格、逐帧核对界面、IPC 拦截、审核保存和时序修改失效。`scripts/test-motion-desktop.cjs` 验证七种现有画风与真实透明桌宠。两项检查禁止模型调用；测试通过仍不等于生成图像的美术与解剖质量自动得到保证。
