# 陪伴主页的排版方向

本轮依据实际界面与以下公开原始资料调整，保留 Demiurge 自己的角色素材、交互和主题系统：

- [Anthropic frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：先制定颜色、字体和空间方案，再以实际截图评审；减少无信息作用的装饰和重复卡片。
- [AIRI 设计指南](https://github.com/moeru-ai/airi/blob/main/DESIGN.md)及 [Stage Web 页面](https://github.com/moeru-ai/airi/blob/main/apps/stage-web/src/pages/index.vue)：人物拥有连续空间，常用控制保持轻量，详细设置按需打开；强调色跟随角色。
- [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) 的公开界面与功能说明：人物展示、聊天和桌宠控制属于同一陪伴体验。参考空间层级，不复制其素材或代码。

## 两步设计计划

上一版的问题是左侧大标题、右侧小人物、宽回复卡片和另一张输入卡片竞争视觉焦点。首页重复显示角色名、服务状态和模式说明；几乎所有按钮都有边框，陪伴区被割裂。

本轮采用一个连续的陪伴区域。人物位于中央、保留完整轮廓；姓名和作品在左上角形成安静的身份区；回复靠近人物右侧。人物下方直接接输入框；触摸互动在人物上进行，休息/唤醒收在人物设置内。外观选择放在下方，通过明确入口进入完整工作台。

```text
角色列表    姓名 / 作品                       人物设置
            档案             人物     当前回复气泡
                             人物
                  点击人物头部 / 身体互动
                  对话选项             展开对话
                  [消息输入             发送]
                  其他外观 / 全部外观
```

昔涟示例颜色为花粉 `#b95882`、淡紫 `#a899cf`、纸白 `#fcf8fa`、墨色 `#493342`、白色 `#ffffff`。其他人物继续使用已有角色主题变量，不能固定套用昔涟的粉色。色彩主要用于人物附近的柔光、可交互状态和发送按钮；阅读区域使用稳定的浅色底。

字体继续使用本机 Manrope/PingFang 作为正文与控制，宋体只用于较小的角色姓名；姓名 30–36px，正文 14px，控制 12px，辅助说明 11px。正文维持可读行高；中文回复限定宽度，长回复可滚动。

评审后舍弃了满页星星、多个轨道圈、大段标语、每项按钮的硬边框和双层输入容器。保留一个安静的地面光影，用人物本身建立视觉辨识度。气泡与输入区使用不同圆角和深度，以表达临时回复与编辑区域的区别。

## 验收

- 默认没有完整聊天记录，只显示当前气泡；展开记录后能搜索并回到原消息。
- 输入区紧接人物下方；1400px、1100px 和 900px 桌面窗口都无需横向滚动。
- 触摸按钮的实际可点击区域与人物展示区域协调，键盘焦点可见。
- 设置默认收起，编辑草稿不会因折叠丢失。
- 操作反馈使用短暂粒子和素材支持的动作；不让整个立绘摇晃。
- 用真实 Electron 截图检查人物比例、文本截断、长回复和打开设置后的遮挡。
- 开发版复用用户已有的角色、外观、配置和对话；验证时不请求付费模型。

## 功能分区

左侧入口增加简短文字，分为人物陪伴、对话语音、角色资料、外观动作、相处记忆、桌宠窗口和连接设置。主页保留紧凑输入，完整聊天记录有单独页面；删除重复的快捷互动工具条。当前先调试人物陪伴，范围与验证见 [功能模块与逐块调试](FUNCTION_MODULES.md)。
