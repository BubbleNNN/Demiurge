# 发布文案

标题：我让昔涟住进了我的桌面。

工作的时候，她在旁边读书；休息的时候，一起听歌、打游戏、发会儿呆。
轻轻摸摸头，她也会回应你。

我想做的，不止是一个昔涟桌宠。
而是让你喜欢的角色，都有机会在桌面活过来。

Demiurge 是一个开源角色陪伴项目：桌面生活、角色对话、相处记忆，以及可以一起共建的桌宠与生活插件共享目录。
目前自带最新版 Q版昔涟，也支持创建和导入其他角色。社区刚刚起步，欢迎分享你的作品。

如果你也喜欢这个方向，来 GitHub 点一颗 Star，或者一起写代码、做动作、分享桌宠吧。
https://github.com/BubbleNNN/Demiurge

音乐：心忆 / Remembrance of the Heart — HOYO-MiX、林一凡。
非官方同人开源项目；部分桌面场景为功能演示合成，窗口感知功能目前仅 macOS 支持。
