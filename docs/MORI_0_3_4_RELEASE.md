# Mori 0.3.4 · 可比较的候选设计方向

此前多候选请求主要通过编号要求模型尝试不同表现。0.3.4 增加明确的设计说明，让每张候选的尝试方向在生成前可见，生成后也可以追溯。它与 0.3.3 的独立画风参考、小尺寸预览一起使用。

## 使用方式

选择两张或三张角色候选后，可切换「候选变化」：

- **探索不同表现**：新建多候选的默认选项。两张依次使用均衡表现、鲜明轮廓；三张再加入柔和神态。
- **同一方向微调**：沿用原来的细微变化方式，不新增设计方向标签。

| 方向     | 设计要求                                                                                 |
| -------- | ---------------------------------------------------------------------------------------- |
| 均衡表现 | 在小尺寸轮廓可读性与角色服装细节之间取得平衡，使用自然待机站姿。                         |
| 鲜明轮廓 | 更清楚地区分头发、四肢和大色块；允许的简化服从画风要求，保留标志性饰物与服装元素。       |
| 柔和神态 | 通过放松的眉眼和自然站姿表现温和感；不靠模糊或平滑改变媒介，像素网格和配色限制继续生效。 |

原作画风使用专门的保守说明，保留原有线条、头身比、材质和细节，只在神态与自然站姿中探索。各方向都必须服从角色身份、服装和选定媒介；独立画风图继续只提供画法参考。

方向不会增加额外请求：三张候选仍是三次基准图请求。必须明确选择一张才会开始动作。单候选与为已有角色图补动作不会启用方向探索。

## 保存与兼容

新任务保存变化方式，生成结果保存其设计方向。候选卡和核对面板展示实际保存的方向，不根据编号给旧图片补造标签。重开任务继续按已保存方式制作；缺少新字段的旧任务采用原行为。

修图和成品修正版保留选中候选的来源方向，后续动作使用其实际图片字节。方向标签表示初始设计意图，不是当前图片一定符合该表现的判定；修图后的实际外观仍以图片与修改要求为准。

## 验证与边界

来源和设计取舍见 [开源调研记录](PET_STYLE_REFERENCE_RESEARCH_2026_10_23.md)。候选说明由 Mori 编写，没有复制第三方角色美术或实现代码。

测试确认不同候选得到不同的设计说明、相同的角色与画风输入，验证来源保存、旧任务兼容、重启和修图继承。测试使用隔离工作区和固定图像响应，不调用收费服务。提示词不同不保证模型输出一定有明显差异，真实多样性、身份和美观度仍需要看图判断。
