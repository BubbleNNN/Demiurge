# Mori 0.3.6 使用指南

Mori 把角色档案、对话、外观、记忆和透明桌宠放在同一个本地工作区。预制角色与本地互动无需账号或 API；自由聊天、生成新图和语音合成使用你自己配置的服务。

## 打开应用

macOS Apple Silicon 本机包位于 `release/Mori-0.3.6-macOS-arm64/Mori.app`。双击打开即可，也可以拖入「应用程序」。ZIP 位于 `release/Mori-0.3.6-macOS-arm64.zip`，适合保留构建副本。应用包自带运行环境，不需要运行终端命令。

当前包供本地使用，未签名或公证。开发与重建步骤、支持范围和包内许可见 [macOS 打包说明](MACOS_RELEASE.md)。Windows、Linux 和 Intel Mac 尚未提供经过验收的发行包。

应用包默认使用 macOS 的 `~/Library/Application Support/Mori`。开发命令 `pnpm desktop` 默认使用项目 `.local/development-v2`，两者是不同工作区。如果要把开发版里的角色和聊天带入应用包，先在开发版导出完整工作区 ZIP，再在应用包内恢复。密钥不在 ZIP 中，需要另行填写。不要直接覆盖正在运行的存档文件。

## 第一次体验

1. 打开「人物陪伴」，点击角色头部或身体，体验本地回应。
2. 在「外观工作台」预览内置七套画风，选中喜欢的角色包再启用。预览不会更换当前桌宠。
3. 对话选项选择「本地台词」，输入“你好”“给我一点鼓励”“晚安”“醒醒”。这些是明确标注的已编写回应，自由问题需要模型对话。
4. 打开「桌宠窗口」，调整大小并显示透明桌宠。支持拖动、触摸和对话，透明区域穿透由窗口设置控制。
5. 在「角色档案」修改称呼、关系、语气和相处节奏；在「相处记忆」查看、编辑、置顶或暂停使用某条记忆。

新增人物可以只填写名字建档；没有可靠证据的作品设定保持为空。已有外观可以导入；制作新外观需要核对参考原图并连接图像服务。

## 制作自己的桌宠

入口为「外观工作台 → 自动制作多画风桌宠」。先保存角色，并准备最多四张参考原图；第一张负责主要服装和轮廓。文字描述和网页链接不能代替图像输入。

在「连接与设置 → 图像」填写图像 Key、接口基础地址和模型。服务必须实际支持 `Images Edits`、原图参考和透明 PNG。聊天接口能连通，不代表它支持绘图。

制作时按以下顺序选择：

1. **画风**：原作画风、精绘、Q 版、飞天小女警、像素、8-bit 或低多边形。可同时选多种，每种独立制作。
2. **外观要求**：描述希望调整的比例、轮廓、材质或细节。身份与服饰仍由原始参考约束。
3. **角色候选**：每画风 1、2 或 3 张。两张或三张会全部生成后停下，供并排比较；只有选定的一张用于后续动作。
4. **帧数与气质**：默认四帧；八帧为实验选项，需要服务支持横向图像。自然、轻柔、活泼同时影响动作提示与播放时间。更多帧不保证更流畅。
5. **动作**：勾选要制作的动作组，并查看预计请求数。默认一张角色图和六组动作是七次图像请求；改为两张角色候选则为八次。

选择两张或三张候选时，可以切换「候选变化」。新建多候选任务默认「探索不同表现」：第一张均衡表现，第二张鲜明轮廓，第三张柔和神态；生成前会显示每张的说明。希望只做细微变化时选「同一方向微调」。候选数量相同，两种模式的图像请求次数相同。

这些标签记录最初的设计要求，不是对图片的自动质量评价。候选卡片和放大面板会显示已保存的方向；后续修图保留其来源，实际外观以结果和你的修改要求为准。原作画风保留原画法、比例和服装细节，只用神态与自然站姿探索变化。单候选、为已确认图补动作，以及没有方向设置的旧任务，继续采用原有流程。

还可以在「画风参考（选填）」中添加一张 PNG、JPEG 或 WebP，单张不超过 8 MiB。角色原图确定人物、服装与配色，画风图用于参考线条、上色方式、材质和细节处理。选择符合目标画风的示例，避免示例中的人物或服装影响目标角色；生成后仍要核对身份。

画风参考随本任务独立保存，重开或修正时沿用原副本。当前任务下方可以查看它；上方用于新任务的图片更换或移除，不会改变已经创建的任务。角色图生成与修图请求会附加这张图片，动作只使用选定角色图和角色原图。不会因此增加请求次数，但供应商可能按输入图片和用量计费。

「原作画风」继续以角色原图的画法为准。多画风同时选择时，独立画风参考只用于其他画风；如果只选原作画风，请移除独立画风参考。为已有确认角色图补动作时，沿用该图的外观，不接收新的画风参考。画风图和文字不能代替角色原图。

开始后，每个阶段都会保存任务与原始图片。单候选默认在角色图完成时暂停，也可关闭这个选项；多候选始终先等选择。点击「选择候选并继续」会保存选择并开始动作制作。

成品不会立即替换桌宠。对照原图试播、逐帧查看，核对肢体、身份和衔接，再确认启用。背景透明、帧数正确只能说明技术格式合格，不能代替视觉审阅。

角色候选卡片上的「放大核对细节」可以打开并排视图：左侧切换任意一张参考原图，右侧切换候选；缩放范围为适应窗口尺寸的 100%–300%，放大后可以滚动查看。透明格、浅色与深色背景用于查看白边、漏抠与半透明细节。像素候选放大保持硬边。这里的候选切换只影响查看，决定使用哪张仍需点击卡片上的「用这张继续」。

核对面板的「预览高度」还可选择 96、160 或 240 像素，按图片比例缩小显示。先看脸部与服装色块是否还清楚，再切回「适应区域」放大查细节。这个选项只改变当前查看尺寸，不修改原图、不调用服务，也不改变桌宠窗口的大小设置。

## 修正不满意的结果

**还在选角色图时**，可以直接点击候选卡片上的「修正这张」。填写具体要求（最多 600 字），例如保留服装和发饰、调整头身比例或清理裙摆边缘，然后点击「生成修正版」。每次提交预计新增一次图像编辑请求，不包含动作。

修正结果会成为新的候选，原图继续保留；完成后可与修正前候选或角色原始参考图并排放大比较。即使关闭了「先看角色图再继续」，候选修图完成后也会等待你明确选择。点击喜欢的一张的「用这张继续」，才会开始制作动作。每画风最多保留六次候选修正记录，每任务最多十二次；失败记录也占用这个上限，明确重试已有失败记录不新增记录。

修图失败或请求中断时，可以选择已有候选继续，也可以明确重试这次修正；重试会新增一次图像请求。若提示结果已经返回但尚未保存，点击「仅恢复本机保存」只保存已有图片，不需要再次调用服务。动作已经开始后，不能回头修改本任务的候选；完成后使用下面的独立修正版。

**整套动画已经完成时**，在成品下方选择「修正范围」，填写具体修正要求。

| 选择                   | 适合的问题                               | 新图像请求                      |
| ---------------------- | ---------------------------------------- | ------------------------------- |
| 只修正一个动作         | 招手多手指、小跳姿势不自然、嘴型不清楚等 | 仅该动作 1 次，其余动作原样复用 |
| 修正角色形象并重做动作 | 比例、脸、服饰或整体画法需要改变         | 角色图 1 次 + 此画风所有动作组  |

每份修正版都有独立记录和修正说明。原成品与原任务保留，当前桌宠继续使用原已确认外观；新版本核对通过后再启用。形象修正是参考图编辑，目前没有局部蒙版画笔，不能保证指定区域以外的每个像素不变。

修正版完成后，动作预览并排显示「修正前」和「本次修正版」。两边共用动作、表情和说话试播按钮；点击招手等有限动作会同时开始，再次点击可重播。只提供两份素材都支持的共同能力，便于直接比较。来源成品暂时无法读取时会说明原因，当前修正版仍可单独试播和逐帧核对。预览不产生新的模型请求。

参考原图或图像模型配置改变时，旧任务会停止并解释原因，避免混用不同输入。未完成的同画风任务需先继续或结束，之后再创建新的修正任务。

## 暂停与失败处理

可以在当前请求结束后暂停，关闭窗口后重新打开同一任务继续。不要为本机保存错误重新创建制作任务。

| 提示                       | 下一步                                                 |
| -------------------------- | ------------------------------------------------------ |
| 等待角色候选选择           | 对照原图选择一张，再继续动作                           |
| 素材已返回，但本机保存失败 | 点「仅恢复本机保存」，不重复请求模型；完成后再单独继续 |
| 图片未通过技术检查         | 查看原因后明确重试当前阶段，其他已完成素材保留         |
| 请求中断且没有保存输出     | 核对服务状态，再决定是否重试；供应商可能已经计费       |
| 图集超限                   | 减少动作或拆分任务，不会自动压低原始画质               |

四帧与八帧的请求数量相同，图像面积和服务收费可能不同。预览、核对、打包、导出及桌面互动不请求图像模型。

## 保存、备份与迁移

「连接与设置 → 工作区备份与恢复」提供三个入口：

- **导出工作区备份**：生成 ZIP，包含已保存的角色、聊天、记忆、外观、模型文件及制作任务。API 密钥、应用缓存和未保存的输入草稿不包含在内。
- **从备份恢复工作区**：先选择文件并校验，保留当前数据副本，再替换工作区。成功后应用重启。本机 API 密钥保持原样；跨电脑使用需要重新配置密钥。
- **打开数据文件夹**：查看实际存档、任务和恢复副本位置。

先结束当前请求和文件导入，再执行备份或恢复。备份与恢复期间暂不接受其他工作区操作。完整 ZIP 上限为 512 MiB 解压后载荷、单文件 128 MiB、10,000 个文件；模型较多时可先另存个别素材。文件集合、路径、校验摘要或存档格式不合格时会拒绝导入。

导入前副本保留在数据目录的 `recovery-*` 中；它用于恢复意外情况，不会自动删除。导入中途退出后，下次启动先完成事务恢复，再加载工作区。若恢复副本或事务记录本身损坏，应用停止加载并显示数据目录，避免继续覆盖数据。

画风参考原文件随制作任务进入完整工作区备份；单独导出角色包只携带外观及画风来源摘要。

角色包导出与完整工作区备份用途不同：角色包用于分享一名角色的档案、图片、逐帧时序和本地台词，不携带聊天、记忆或本机模型；工作区 ZIP 用于保存自己的完整使用数据。

## 存档和密钥故障

正常保存会保留上一份有效存档。启动时若当前存档无法读取，界面提供重新读取、打开数据目录，以及在存在有效副本时「恢复上一份有效存档」。恢复会保留坏文件，并使用新版本号同步桌宠窗口；它只恢复该次快照，不是所有历史版本的时间机器。

如果系统无法解密已保存密钥，本地角色、聊天记录和本地互动仍可使用。「连接与设置」会显示故障说明；点击「重新配置密钥」会保留原加密文件、清除失效凭据，然后再填写需要的密钥。模型请求在配置修复前不会偷偷改用另一个服务。

每个角色的已保存聊天允许最多 100,000 条，并受工作区文件大小上限约束；超限会明确拒绝保存，不会静默截掉旧记录。模型实际接收的近期上下文仍是单独的有界窗口，长历史不会全部发送。

## 当前能力范围

内置逐帧外观、本地互动、档案、聊天管理、记忆、桌宠、模型导入、自动制作、修正版、备份恢复与本机应用包已经接通。真实模型对话、语音和图片输出取决于所配置的服务。

八帧流程尚属实验；没有自动视觉审美评审、Live2D 自动拆层绑定、语音识别或自动更新。已有 Live2D/VRM 可以导入运行；低多边形画风的逐帧图仍是 2D，真实 3D 制作有独立服务入口。候选修图仍由图像服务按参考图编辑，不能保证只改变指定区域。实现细节与验证证据见 [0.3.0 完善记录](MORI_0_3_RELEASE.md) 和 [0.3.2 候选修图改进](MORI_0_3_2_RELEASE.md) 和 [0.3.3 画风参考与预览](MORI_0_3_3_RELEASE.md)、[0.3.4 候选设计方向](MORI_0_3_4_RELEASE.md)。

## 清爽贴纸与图集整理（0.3.5）

在「外观工作台 → 自动制作多画风桌宠」选择「清爽贴纸」，可生成两头身、深色轮廓、单层平涂的角色。先核对基准，再继续动作。等分图集的轻微尺寸偏差会本机补透明边；原图保持不变。成品说明会显示补边与低透明度清理记录。人物被裁切或帧没有足够可见变化仍需处理，不能用补边修复已经缺失的肢体。详见 [0.3.5 说明](MORI_0_3_5_RELEASE.md)。

## 读书与掌机（0.3.6）

在自动制作中勾选读书或玩掌机，每组固定八帧、一次 1536×1024 请求；先确认形象，生成后核对所有姿势。启用后，可在外观工作台的动作区或桌宠工具栏触发活动，约一分钟后收起道具，也可点击停止。已有角色必须具有对应素材才会启用这些按钮；内置七套外观没有自动增加新帧。具体流程见 [生活活动说明](MORI_0_3_6_RELEASE.md)。
